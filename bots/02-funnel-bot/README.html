Бот-воронка для эксперта

Концепт для портфолио, бренд и данные вымышлены. Эксперта «Веру Лунёву» я придумал.

Классическая история: у эксперта есть блог, люди подписываются, читают — и ничего не покупают, потому что непонятно, что именно им подойдёт. Этот бот проводит человека от «забрать бесплатный материал» до заявки на конкретный продукт и по дороге сам решает, что ему предложить.

Как устроена воронка

  1. Приветствие. Коротко объясняет, кто эксперт и чем бот полезен.
  2. Подарок. Человек получает PDF-чек-лист «12 проверок профиля перед запуском рекламы». Файл лежит в assets/checklist.pdf.
  3. Квиз из 4 вопросов. Где вы сейчас, как часто публикуете контент, откуда приходят клиенты, какой бюджет на продвижение.
  4. Определение этапа. По сумме баллов человек попадает в один из трёх этапов: «Старт», «Рост» или «Система». К каждому идёт свой разбор: что сейчас важнее всего.
  5. Предложение под этап. Новичку — недорогой мини-курс, тому, кто растёт, — интенсив, опытному — личный аудит. Кнопки «Хочу», «Подробнее», «Не сейчас».
  6. Заявка. Имя и контакт: телефон кнопкой, вручную или ник в Telegram. Заявка сохраняется в базу и сразу приходит админу вместе со всеми ответами из квиза. На созвон эксперт идёт уже подготовленным.

Ещё у админа есть команда /stats: сколько человек зашло в бота, забрало чек-лист, прошло квиз и оставило заявку по каждому этапу. Это реальные цифры из базы, по ним видно, на каком шаге люди отваливаются.

Как запустить (5 шагов)

  1. Поставьте Python 3.10 или новее и откройте терминал в этой папке.
  2. Создайте окружение и установите зависимости:
    python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
    На macOS и Linux вместо второй строки: source .venv/bin/activate.
  3. Напишите @BotFather в Telegram, создайте бота и скопируйте токен.
  4. Скопируйте .env.example в .env, впишите BOT_TOKEN и свой ADMIN_ID (числовой ID покажет @userinfobot).
  5. Запустите python bot.py и напишите боту /start.

Как сделать под себя

  • Все тексты, вопросы, баллы, этапы и продукты лежат в одном файле — content.py. Код трогать не нужно.
  • Свой лид-магнит: положите PDF в папку assets/ и пропишите путь в .env в строку CHECKLIST_PATH.
  • Заглушку чек-листа можно пересобрать: pip install pymupdf, затем python make_checklist.py.

Проверка без Telegram

python smoke_test.py проходит всю воронку на подменённом Telegram. Бот выдаёт PDF, не даёт оставить заявку до квиза, правильно считает этапы, проверяет контакт, уведомляет админа, а /cancel прерывает заявку. Токен не нужен.

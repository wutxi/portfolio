# Бот записи в барбершоп «Кирпич»

> Концепт для портфолио, бренд и данные вымышлены. Барбершоп, мастера и адрес я придумал.

Типичная боль маленького салона: администратор весь день отвечает в личке «а на завтра есть время?». Этот бот берёт запись на себя. Клиент сам выбирает услугу, мастера, день и свободное окно, а мастер получает уведомление о новой записи.

## Что умеет

- **Запись по шагам.** Услуга → мастер → день в календаре → свободное время → телефон → подтверждение. Мастеров бот показывает только тех, кто делает выбранную услугу.
- **Нормальный календарь прямо в чате.** Можно записаться на 14 дней вперёд, выходные мастера недоступны.
- **Только реально свободные окна.** Бот учитывает длительность услуги: если «стрижка + борода» идёт 90 минут, он не предложит время, которое налезает на чужую запись.
- **Защита от двойной записи.** Перед сохранением бот ещё раз проверяет слот. Если его успели занять, предложит выбрать другое время.
- **Уведомления админу** о каждой новой записи и каждой отмене.
- **Отмена.** Команда `/my` показывает будущие записи, отменить любую можно одной кнопкой.
- **Напоминание за 2 часа** до визита приходит само.
- **Записи на сегодня** — админ может посмотреть их командой `/today`.
- **Передумали** — `/cancel` прерывает запись на любом шаге.

## Как запустить (5 шагов)

1. Поставьте Python 3.10 или новее и откройте терминал в этой папке.
2. Создайте окружение и установите зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
   На macOS и Linux вместо второй строки: `source .venv/bin/activate`.
3. Напишите @BotFather в Telegram, создайте бота и скопируйте токен.
4. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` и свой `ADMIN_ID` (числовой ID покажет @userinfobot).
5. Запустите `python bot.py` и напишите боту `/start`.

Бот работает, пока открыт терминал. Чтобы он работал круглосуточно, его надо запустить на сервере. С этим я тоже помогаю.

## Как поменять под свой салон

Всё лежит в `keyboards.py`:
- `SERVICES` — услуги, длительность и цены;
- `MASTERS` — мастера, что они умеют и в какие дни отдыхают;
- `OPEN_HOUR` и `CLOSE_HOUR` — часы работы, `HORIZON_DAYS` — на сколько дней вперёд можно записаться.

Часовой пояс задаётся в `.env` (`TZ_NAME`), по умолчанию московский.

## Проверка без Telegram

`python smoke_test.py` подменяет Telegram и прогоняет весь путь: запись, уведомление админу, занятость слота, отмену и напоминание. Токен для этого не нужен.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `bot.py` | логика бота, шаги записи, напоминания, запуск |
| `keyboards.py` | услуги, мастера, календарь и кнопки |
| `db.py` | база записей в SQLite |
| `smoke_test.py` | проверка без Telegram |

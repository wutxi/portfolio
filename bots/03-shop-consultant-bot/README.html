Бот-консультант для чайной лавки «Лист и пар»

Концепт для портфолио, бренд и данные вымышлены. Лавки не существует, товары и цены я придумал.

Хотелось сделать бота, который заменяет продавца в маленьком магазине: человек заходит, смотрит каталог, задаёт вопросы, собирает корзину и оставляет заявку. А владелец получает готовый заказ в личку и просто перезванивает.

Что умеет

  • Каталог кнопками. Разделы → товары → карточка с ценой и описанием → «В корзину».
  • Частые вопросы. Доставка, оплата, возврат, хранение, как заваривать, адрес и часы. Тексты лежат в catalog.py, их легко поменять.
  • Подбор за 3 вопроса. Какой вкус нравится, когда пьёте чай, какой бюджет. Бот предлагает три подходящих варианта. Если человек пьёт чай вечером, бот покажет только напитки без кофеина.
  • Корзина. Плюс/минус, очистка. Бот подсказывает, сколько не хватает до бесплатной доставки.
  • Оформление заказа. Имя → телефон → самовывоз, курьер или пункт выдачи → адрес → подтверждение. Заказ сохраняется в базу и сразу прилетает админу.
  • Умные ответы (по желанию). Если подключить ключ Claude API, бот начинает отвечать на вопросы, написанные своими словами: «что подарить маме, она любит цветочный чай?» Отвечает только по ассортименту и условиям лавки, ничего не выдумывает. Без ключа этот режим просто выключен, всё остальное работает.

Как запустить (5 шагов)

  1. Поставьте Python 3.10 или новее и откройте терминал в этой папке.
  2. Создайте окружение и установите зависимости:
    python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
    На macOS и Linux вместо второй строки: source .venv/bin/activate.
  3. Напишите @BotFather в Telegram, создайте бота и скопируйте токен.
  4. Скопируйте файл .env.example в .env и заполните:
    • BOT_TOKEN — токен от BotFather;
    • ADMIN_ID — ваш числовой ID в Telegram (его покажет @userinfobot), сюда будут приходить заказы;
    • ANTHROPIC_API_KEY — только если нужны умные ответы, про это ниже.
  5. Запустите python bot.py и напишите боту /start.

Что такое API-ключ и зачем он нужен

Умные ответы пишет не сам бот, а нейросеть Claude от компании Anthropic. Бот отправляет ей вопрос покупателя вместе с каталогом и получает готовый ответ. Чтобы Anthropic понимала, кто отправляет запросы и с кого брать деньги, нужен API-ключ. Это длинная строка вида sk-ant-..., что-то вроде пароля от вашего аккаунта.

Как получить:

  1. Зарегистрироваться на console.anthropic.com.
  2. Пополнить баланс в разделе Billing. Оплата по факту использования, подписки нет, минимальное пополнение — 5 долларов. Нужна карта зарубежного банка: российские карты там не принимают.
  3. В разделе API Keys нажать Create Key, скопировать ключ и вставить в .env в строку ANTHROPIC_API_KEY=.

Ключ никому не показывайте и не выкладывайте в открытый доступ: с ним любой сможет тратить ваш баланс. Если ключ утёк, удалите его в консоли и создайте новый.

Сколько это стоит

Платите за объём текста, который нейросеть прочитала и написала. Текст считают в токенах, грубо: один токен — это 3–4 символа русского текста. Цены за миллион токенов (на октябрь 2026, актуальные — на странице с тарифами Anthropic):

МодельЧтениеОтветКогда брать
claude-opus-5-5 (стоит по умолчанию)4 $20 $самые точные и аккуратные ответы
claude-haiku-5-50,10 $0,50 $дешёвый вариант для простых вопросов

Один вопрос покупателя — это примерно 2 000 токенов на чтение: каталог, условия лавки и сам вопрос. Ответ — около 500 токенов. Получается так:

  • Opus 5.5: около 0,02 $ за ответ, то есть 1,5–2 ₽. Тысяча вопросов в месяц — примерно 18 $.
  • Haiku 5.5: около 0,0005 $ за ответ, меньше 5 копеек. Тысяча вопросов — меньше 1 $.

Для чайной лавки с вопросами вроде «что взять к десерту» хватит Haiku. Чтобы переключиться, впишите в .env строку CLAUDE_MODEL=claude-haiku-5-5. В консоли Anthropic можно поставить месячный лимит расходов: тогда точно не выйдете за бюджет.

Ещё одна мелочь: на моделях Opus 5.5, Opus 5, Sonnet 5.5 и Fable 5.1 у меня включён запасной вариант. Если модель откажется отвечать, вопрос автоматически подхватит другая модель. Отключается в smart.py, список FALLBACK_MODELS.

Проверка без Telegram

python smoke_test.py прогоняет весь сценарий на подменённом Telegram: каталог, корзину, вопросы, подбор, оформление заказа с бесплатной доставкой и уведомление админу. Умный режим тоже проверяется, но вместо настоящей нейросети подставляется заглушка, так что ни ключ, ни деньги не нужны.

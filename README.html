Моё портфолио: сайты, Telegram-боты, презентации

Концепт для портфолио, бренд и данные вымышлены. Все компании, люди, адреса, телефоны и цены в работах я придумал. Отзывов и громких цифр вроде «нам доверяют тысячи клиентов» тут специально нет: это демо-работы, а не реальные заказы.

Привет! Я делаю сайты, Telegram-ботов, презентации под ключ: для малого бизнеса и экспертов. В этой папке собраны работы, на которых видно, как я это делаю. Каждая работа — не просто картинка, а рабочая вещь: на сайтах можно записаться и посчитать стоимость, ботов можно запустить, презентации открываются в PowerPoint.

Писать мне в Telegram: @primewutxi.

С чего начать

Откройте index.html двойным кликом — это главная страница портфолио. Оттуда есть ссылки на всё остальное.

Что внутри

Сайты (папка sites/). Шесть сайтов для разных ниш, и у каждого свой характер:

  • Барбершоп «Кирпич» — тёмный, с латунью. Прайс, мастера и запись: выбираешь услугу, мастера и свободное время.
  • Кофейня «Тихая полка» — как журнал о кофе. Меню с фильтром, кофе недели с рецептами и бронь столика прямо на схеме зала.
  • Онлайн-школа «Лингвомост» — яркая и геометричная. Тест уровня из 5 вопросов с объяснениями, программа по неделям и тарифы.
  • Студия йоги «Тёплый вдох» — спокойная, пастельная. Расписание с фильтром по уровню, абонементы и запись на пробное.
  • Ремонт «Отвес» — строгий, как чертёж. Калькулятор стоимости ремонта, этапы работ и примеры смет.
  • Детейлинг «Блик» — чёрно-белое стекло. Калькулятор стоимости по классу авто, вопросы и запись на осмотр.

Каждый сайт — один файл index.html, открывается в любом браузере. Шрифты подгружаются из интернета, поэтому без сети вид будет попроще.

Telegram-боты (папка bots/). Три бота на Python. У каждого своя страница с демо-перепиской, описанием, инструкцией «как запустить за 5 шагов» и всем кодом:

  • Запись в барбершоп — календарь, свободные окна, отмена и напоминание за 2 часа.
  • Воронка для эксперта — подарок в PDF, квиз, подбор продукта и заявка.
  • Консультант магазина — каталог, корзина, подбор чая и умные ответы через нейросеть Claude.

Презентации (папка decks/). Три презентации по 10 слайдов, все в разном стиле:

  • «10 задач малого бизнеса, которые можно отдать нейросети» — тёмная, чёрно-красная, с готовыми промптами;
  • «Личный бренд эксперта за 30 дней» — светлая, в журнальном стиле с засечками;
  • «Личный бюджет за один вечер» — свежая, зелёная, со скруглёнными блоками.

У каждой своя страница, где слайды можно полистать прямо в браузере, и рядом лежат файл для PowerPoint (deck.pptx) и PDF (deck.pdf).

Если что-то не открывается

Иногда браузер ругается на локальные файлы. Тогда откройте терминал в папке portfolio, выполните

python -m http.server 8000

и зайдите в браузере на http://localhost:8000.

Для тех, кто хочет покопаться

В папке tools/ лежат мои скрипты проверки:

  • check_sites.py открывает все сайты в Chrome на ширине 1280, 390 и 360 пикселей. Он ловит горизонтальную прокрутку и ошибки, прокликивает интерактив и обновляет скриншоты для главной.
  • render_pptx.py превращает презентацию в картинки и PDF и проверяет, что текст нигде не вылезает за рамки.
  • build_pages.py собирает страницы проектов: у каждого бота — демо-переписка, описание и код с подсветкой, у каждой презентации — листалка слайдов и кнопки скачивания. Если поменяли README бота или пересобрали презентации, запустите его ещё раз.
  • build_readme_html.py делает HTML-версии README (им же пользуется build_pages.py).

Презентации собираются кодом: cd decks и python build_decks.py --render. Нужны pip install python-pptx playwright и установленный Google Chrome.

Сайты сделаны на чистом HTML, CSS и JavaScript, боты — на Python и aiogram 3, презентации — на python-pptx.
